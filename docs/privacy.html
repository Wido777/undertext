Privacy policy

Last updated 18 October 2026

undertext does not collect, store, share or sell any information about you. The browser extension and the website run entirely on your device and send nothing anywhere. The command-line tool only goes online when you ask it to.

Who we are

undertext is an open-source project by Wido777. All of its code is public on GitHub, so you can check everything this page says. This policy covers the browser extension, this website and the command-line tool.

Browser extension

  • What it reads. The content of the web pages you visit: their text, links, hidden elements, comments, image descriptions and page metadata. It reads these to look for instructions hidden for AI and for links to AI assistants that carry a prefilled prompt.
  • Where it runs. Entirely in your browser. The check happens on the page itself and the result is passed only to the extension's own toolbar button and pop-up.
  • What it stores. Nothing. It does not use browser storage, cookies or any other way of keeping data. Results disappear when you leave or close the page.
  • What it sends. Nothing. It makes no network requests at all, so no page content, browsing history or results ever leave your device.

It requests no browser permissions. The only access it has, and why:

  • Content scripts on web pages (http and https only). This lets it check each page as it loads and show a warning badge. Chrome describes this as being able to read your data on all websites; undertext only reads it to run the check, locally.

There is no analytics, no tracking, no advertising and no third-party code in the extension. We do not sell or share data, because we never have any.

Website checker

The checker on this website runs in your browser. Links and page code you paste are checked on your device and never leave it. The site loads nothing from other servers: no third-party scripts, fonts, analytics or cookies, and its security policy stops the page from sending data to any server.

The site is hosted on GitHub Pages. Like any web host, GitHub may keep standard server logs (such as IP addresses) when you visit. That is handled under GitHub's privacy statement; we have no access to those logs.

Command-line tool

The command-line tool runs on your own computer. It only makes network requests when you ask it to:

  • when you give it a page address to check, or use --follow, it downloads that page;
  • when you use --ai, it sends the text being checked to the AI provider you choose. With ollama that is a model on your own machine by default. With openai or anthropic, the text goes to that company under their terms, using your own API key.

Your API key is read from your environment each time and is never saved by the tool. Nothing is sent to us.

Changes and contact

If this policy changes, the new version will be posted on this page with a new date, and the change will be visible in the project's public history on GitHub.

Questions or concerns? Open an issue on GitHub.
